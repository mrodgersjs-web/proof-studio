# Evaluation strategy

## Gates

| Gate | Command | Pass |
| --- | --- | --- |
| Planted failures | `proof-studio run` | exit 0: every scenario reaches its expected verdict |
| Test suite | `pytest -q` | all tests green, no new skips |
| Lint | `ruff check .` | clean |
| Smoke | `bash scripts/smoke.sh` | exit 0 |
| Vectors reproducible | `proof-studio build-vectors` + test | regenerated bytes equal the committed vectors |
| Boundary | `docs/public-boundary.md` exists | file present, no secrets in tree |

## Failure policy

If `proof-studio run` or the test suite fails, README promises are considered
false until fixed. A planted failure that passes verification is a release
blocker: the point of the repo is that forgeries go red.

## Human approval

Required before any outward or customer action in real deployments. This public
repo only proves local/demo gates and executes nothing outward.
